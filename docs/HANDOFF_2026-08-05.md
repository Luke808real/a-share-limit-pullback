## 7. 已知缺陷/坑（重要）

1. Tencent 日线 volume 单位按股票/量级变化（手或股）——reconciliation 必须
   unit-aware（×1/×100 匹配 TDX 股数，容差 0.5%），不能假设单位。
2. rank_biserial 并列排名处理已修复（平均秩+零方差）；旧报告离散效应作废。
3. `python -m limit_pullback.cli` 不执行 main（缺 `__main__` 守卫）；用
   `python -m limit_pullback` 或直接调 `main([...])`。
4. runner V01 的 score 路径对 V01 reference 是坏的（缺 component CDF）——勿用 V01
   启动 Forward；用 `--protocol v02`。
5. 新浪 1m 只覆盖近 ~8 交易日；5m 约 800 bar（~16 交易日）——TDX 同理；不要依赖
   长期历史分钟回补。
6. 冻结 forward 语义：VOLUME_PACE 缺失 → NA/INCOMPLETE；禁止 Sina/TDX 互相补洞；
   Q1-Q4 quartile 规则 score<=Q25→Q1…>Q75→Q4；EOD 数据禁止进入 checkpoint predictor。
